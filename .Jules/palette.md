## 2025-02-01 - Form Accessibility and Guidance
**Learning:** Adding explicit required field indicators (*) and descriptive help tooltips in Streamlit forms significantly improves accessibility and reduces cognitive load for users, especially when multiple fields are presented.
**Action:** Always include 'help' parameters in Streamlit input widgets for complex or multi-field forms to provide inline guidance.

## 2025-02-01 - Input Constraints Visibility
**Learning:** Streamlit's `st.text_area` with `max_chars` provides a helpful built-in character counter that gives users real-time feedback on input length constraints.
**Action:** Use `max_chars` for text areas to prevent database overflow and improve user experience via immediate visual feedback.
